    Function lexicalToOdt

    • lexicalToOdt(
          editorState: LexicalSerializedEditorState,
          options?: LexicalToOdtOptions,
      ): Promise<Uint8Array<ArrayBufferLike>>

      Convert a Lexical SerializedEditorState to a valid ODT file.

      Produces a ZIP-packaged .odt file that passes the OASIS ODF validator. Works in Node.js 22+, browsers, Deno, Bun, and Cloudflare Workers.

      Parameters

      • editorState: LexicalSerializedEditorState

        The Lexical serialized editor state (from editor.getEditorState().toJSON()).

      • Optionaloptions: LexicalToOdtOptions

        Page format, margins, and image resolution callback.

      Returns Promise<Uint8Array<ArrayBufferLike>>

      Promise resolving to a valid .odt file as a Uint8Array.

      Example

      import { lexicalToOdt } from "odf-kit/lexical"

      const bytes = await lexicalToOdt(editorState, { pageFormat: "A4" })

      Example

      // With image resolution
      const bytes = await lexicalToOdt(editorState, {
        pageFormat: "A4",
        fetchImage: async (src) => {
          const response = await fetch(src)
          return new Uint8Array(await response.arrayBuffer())
        },
      })
