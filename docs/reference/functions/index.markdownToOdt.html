    Function markdownToOdt

    • markdownToOdt(
          markdown: string,
          options?: HtmlToOdtOptions,
      ): Promise<Uint8Array<ArrayBufferLike>>

      Convert a Markdown string to an ODT file.

      Internally converts Markdown → HTML via marked, then HTML → ODT via htmlToOdt. All HtmlToOdtOptions apply — page format, orientation, margins, metadata, and the substitution hooks (normalizer and parser) for users with custom HTML processing requirements.

      Supported Markdown: CommonMark spec — headings, paragraphs, bold, italic, strikethrough, unordered and ordered lists, nested lists, tables, blockquotes, fenced code blocks, inline code, horizontal rules, and links.

      Page format: Defaults to A4, the ISO standard for Europe and most of the world. Pass { pageFormat: "letter" } for US/Canadian users.

      Parameters

      • markdown: string

        Markdown string to convert.

      • Optionaloptions: HtmlToOdtOptions

        Optional page format, margins, orientation, and metadata.

      Returns Promise<Uint8Array<ArrayBufferLike>>

      Promise resolving to a valid .odt file as a Uint8Array.

      Example

      // Basic usage — A4 page (default)
      import { markdownToOdt } from "odf-kit";
      const bytes = await markdownToOdt("# Hello\n\nWorld");

      Example

      // US letter with metadata
      const bytes = await markdownToOdt(markdownString, {
        pageFormat: "letter",
        metadata: { title: "My Document", creator: "Alice" },
      });
