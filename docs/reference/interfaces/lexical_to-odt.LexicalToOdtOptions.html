    OptionalfetchImage

    fetchImage?: (src: string) => Promise<Uint8Array<ArrayBufferLike> | undefined>

    Callback to resolve an image URL to raw bytes.

    Called when an image src is not a base64 data URL. If not provided, non-base64 images are skipped with a console warning. If provided but returns undefined, the image is skipped with a console warning.

    Type Declaration

      • (src: string): Promise<Uint8Array<ArrayBufferLike> | undefined>

      • Parameters

        • src: string

          The image URL from the Lexical node.

        Returns Promise<Uint8Array<ArrayBufferLike> | undefined>

        The raw image bytes, or undefined to skip the image.

    Example

    fetchImage: async (src) => {
      const response = await fetch(src)
      return new Uint8Array(await response.arrayBuffer())
    }
