    Interface TextSpan

    A single run of inline content with optional character formatting.

    A paragraph or heading is made up of one or more TextSpan objects. Adjacent runs with different formatting are kept separate. A span with lineBreak set to true represents a text:line-break/ element and carries an empty text string.

    Tier 2 additions:

    • hidden: set when text:display="none"; renderers should skip the run.
    • style: visual properties; absent entirely when none are set so Tier 1 consumers never need to check for it.
    interface TextSpan {
        bold?: boolean;
        hidden?: true;
        href?: string;
        italic?: boolean;
        lineBreak?: true;
        strikethrough?: boolean;
        style?: SpanStyle;
        subscript?: boolean;
        superscript?: boolean;
        text: string;
        underline?: boolean;
    }
