    OptionalnumFormat

    numFormat?: "1" | "a" | "A" | "i" | "I"

    Number format for numbered lists. Ignored for bullet lists.

    • "1" — Arabic numerals: 1, 2, 3 (default)
    • "a" — lowercase alpha: a, b, c
    • "A" — uppercase alpha: A, B, C
    • "i" — lowercase roman: i, ii, iii
    • "I" — uppercase roman: I, II, III
